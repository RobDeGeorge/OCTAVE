What is OCTAVE?

OCTAVE is a fully programmable infotainment system designed for vehicles. It pairs a C++ / Qt 6 backend — the shipped binary on every platform — with a parallel Python / PySide6 backend for desktop development and tinkering, both driving a single shared QML frontend. It runs on Windows, macOS, Linux, Raspberry Pi, and Android. OCTAVE is purpose-built for older vehicles with outdated or missing infotainment systems, but works anywhere you want a rich media and diagnostics experience.

The typical installation uses a Raspberry Pi (or equivalent SBC), a proportionate touchscreen, a power source, a 3D-printed mount, and a speaker interface. Development and testing can happen on any desktop OS.

Core Features

♫
Local Media Player
MP3, M4A, FLAC playback with album art carousel, shuffle/repeat, playlist management, and FFT waveform visualization.
♬
Spotify Integration
Full Spotify Connect with OAuth2 authentication, device switching, playback control, and secure keyring token storage.
>_
OBD-II Diagnostics
50+ vehicle parameters via ELM327 adapter. RPM, speed, coolant temp, fuel level, O2 sensors, DTC codes, and configurable gauge layouts.
☏
Phone Mirror & Android Auto
Mirror your phone screen via scrcpy or run Android Auto through Google's Desktop Head Unit with touch forwarding.
↧
Music Download
Search and download music with Spotify metadata matching and YouTube audio extraction. Auto-adds to your library.
⚙
Hardware Integrations
ESP32 wireless volume knob (ESP-NOW), BerryIMU v3 9DOF sensor fusion (Madgwick AHRS), PAJ7620U2 gesture recognition.
◆
Dynamic Theming
UI colors adapt in real-time to album art. Accent, background, and text colors extracted and applied across all views.
∿
Waveform Visualizer
Real-time FFT waveform visualization with 96 frequency bars at 60 FPS, rendered directly in QML.

Platform Support

Platform Status Notes
Linux (Debian/Arch/Fedora) Full support Primary development target. All features available.
Raspberry Pi Full support Recommended for vehicle installation. All hardware I2C sensors supported.
Windows 10+ Full support All features except I2C hardware (BerryIMU, gesture sensor).
macOS 10.14+ Full support All features except I2C hardware.
Android Experimental C++ / Qt 6 .apk built by CI. OBD over Bluetooth, YouTube Music search and download. Phone mirror and Android Auto are desktop-only.
