OBDManager

backend/obd_manager.py — QML name: obdManager

OBD-II vehicle diagnostics via python-obd. Uses a dedicated QThread worker for non-blocking connection. Supports 87+ PIDs, DTC reading/clearing, and vehicle scanning.

Sensor Signals (87+ total)

Each emits float when the sensor value updates. Original 18 core signals:

SignalOBD PIDUnit
rpmChangedRPMrev/min
speedMPHChangedSPEEDmph
coolantTempChangedCOOLANT_TEMPdeg F
voltageChangedCONTROL_MODULE_VOLTAGEV
engineLoadChangedENGINE_LOAD%
throttlePositionChangedTHROTTLE_POS%
intakeAirTempChangedINTAKE_TEMPdeg F
timingAdvanceChangedTIMING_ADVANCEdegrees
massAirFlowChangedMAFg/s
airFuelRatioChangedCOMMANDED_EQUIV_RATIOratio
fuelLevelChangedFUEL_LEVEL%
intakeManifoldPressureChangedINTAKE_PRESSUREkPa
shortTermFuelTrimChangedSHORT_FUEL_TRIM_1%
longTermFuelTrimChangedLONG_FUEL_TRIM_1%
oxygenSensorVoltageChangedO2_B1S1V
fuelPressureChangedFUEL_PRESSUREkPa
engineOilTempChangedOIL_TEMPdeg F
ignitionTimingChangedIGNITION_TIMINGdegrees

Additional signals include: runTimeChanged, barometricPressureChanged, ambientAirTempChanged, catalystTempB1S1Changed/B1S2/B2S1/B2S2, 8 wide-range O2 voltage signals (o2S1WRVoltageChanged through o2S8WRVoltageChanged), 8 wide-range O2 current signals, and many more. See backend/obd_manager.py for the complete list.

SettingsManager

backend/settings_manager.py — QML name: settingsManager

Central settings store with 60+ signals, 60+ properties, and 60+ save slots. See Settings Reference for the complete list of every setting with its type and default. Key patterns:

Signal Naming Convention

Every setting follows the pattern: {propertyName}Changed signal, {propertyName} Property, save_{snake_case_name}() Slot.

// Example: themeSetting
Signal:  themeSettingChanged(str)
Property: themeSetting -> str  (notify: themeSettingChanged)
Slot:    save_theme_setting(str)

SlotParametersReturnsDescription
setCurrentVolume(int)int (0-100)-Set unified volume across all audio outputs

reset_to_defaults()--Reset all settings to factory defaults
get_setting(str)keyQVariantGeneric get any setting by key
save_setting(str, QVariant)key, value-Generic save any setting by key
toggle_pin_setting(str)setting_id-Pin/unpin a setting to Quick Panel

VolumeController

backend/volume_utils.py / src/managers/volumecontroller.cpp — QML name: volumeController

The single entry point for volume. Every slider, knob and gesture calls applyVolume(percent); the quadratic curve lives in one place and volumeApplied fans the result out to MediaManager, SpotifyManager, PhoneMirrorManager and the ESP32 LED.

MemberKindParameters / ReturnsDescription
applyVolume(percent)Slotint 0–100Clamps, persists currentVolume, computes the linear value and emits volumeApplied
toLinear(percent)Slotfloat → float 0–1Pure curve math for QML previews; does not dispatch
volumeAppliedSignalint percent, float linearAfter every applyVolume
