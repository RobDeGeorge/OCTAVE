Signals & Slots API (moved)

This page used to list every manager's properties, methods and signals by hand. That list now lives in two places.

Where It Went

  • The full list of members is the Service API Reference. It is generated from the C++ code, so it is always complete and current. The same names work from QML and over the service protocol.
  • What each object is for, and the few calls most code needs, is on the page for its topic. The table below says which.

A link to an object's old section on this page takes you to its entry in the API reference.
