AlbumArtCarousel

frontend/AlbumArtCarousel.qml is the album art display component used in MediaRoom. It supports two categories of transition animations and configurable visual modes.

Animation Modes

ModeConditionStyles Available
Single-cardpreviewEnabled: falseCrossfade, Slide, Vinyl Lift, Dissolve, Flip
3D previewpreviewEnabled: trueCoverflow, Conveyor, Stack, Depth, Swing

When 3D preview is active, previous and next side cards are visible at idle, and all three cards participate in the transition animation.

Public API

// Navigation direction
property int direction: 1

// Art sources (center, previous, next)
property url artSource: ""
property url prevArtSource: ""
property url nextArtSource: ""

// Animation state
property bool animBusy: false

// Transition configuration
property string transitionStyle: "Crossfade"
property string transition3DStyle: "Coverflow"

// Visual settings
property bool previewEnabled: false
property bool roundedArt: false
property real artRadius: 0
property bool vinylMode: false
property real sideCardAngle: 30
property real sideCardOpacity: 0.4
property bool showShadow: false

// Vinyl rotation tracking
property real playbackPosition: 0
property real playbackDuration: 0

// Dissolve state (exposed for background sync)
readonly property bool dissolveActive
readonly property real dissolveProgress
readonly property url dissolveNewArt

// Signals
signal animationFinished()
signal settled()
signal artClicked()
signal artLoadFailed()

Dissolve Sync: The dissolve animation exposes its progress and new art source as readonly properties so the parent (MediaRoom) can sync the blurred background transition with the album art dissolve.

CoverflowCard

frontend/CoverflowCard.qml is a single album art card with 3D perspective transform, used by AlbumArtCarousel for coverflow-style animations.

Properties

// Coverflow transform properties (animated by parent)
property real cfOffset: 0     // X translation
property real cfAngle: 0      // Y-axis rotation angle
property real cfScale: 1.0    // Scale factor
property real cfOpacity: 1.0  // Opacity

// Image configuration
property url artSource: ""
property real artSize: width
property bool asynchronous: true

// Masking modes
property bool roundedArt: false
property bool vinylMode: false
property real artRadius: 0
property Item roundedMask: null   // Shared mask texture
property Item vinylMask: null     // Shared mask texture

// Vinyl rotation (center card only)
property real vinylAngle: 0

// Drop shadow (center card only)
property bool showShadow: false

3D Transform

The card applies a Translate and Rotation transform to create the coverflow perspective effect:

transform: [
    Translate { x: root.cfOffset },
    Rotation {
        axis { x: 0; y: 1; z: 0 }
        angle: root.cfAngle
        origin.x: root.width / 2
        origin.y: root.height / 2
    }
]
GPU Optimization: Mask items (roundedMask, vinylMask) are passed in from the parent rather than created per-card, avoiding duplicate GPU texture allocations.

LazyImage

frontend/LazyImage.qml is a visibility-aware image loader for use in lists and grids. It only loads its source when the component is visible.

Properties

property string source          // Image URL/path
property bool rounded: false     // Enable rounded corners
property int fidelity: 60       // sourceSize (lower = faster load)
property bool smoothing: false  // Enable smooth filtering
property bool mipmap: false     // Enable mipmapping
property bool antialiasing: false
property real quality: 0.0      // Image decode quality
property int cacheLimit: 2048   // Cache size in KB

Implementation

Image {
    source: root.visible ? root.source : ""
    asynchronous: true
    cache: true
    sourceSize.width: root.fidelity
    sourceSize.height: root.fidelity
    visible: status === Image.Ready
}

The key optimization is source: root.visible ? root.source : "". When a LazyImage scrolls off-screen, its source is cleared, freeing the decoded image from memory. The low fidelity default (60px) means thumbnail-sized images decode very fast.

Usage Example

LazyImage {
    source: mediaManager.get_album_art(filename)
    fidelity: 60
    width: App.Spacing.mediaPlayerAlbumArtSize
    height: width
}

GForceDisplay

frontend/GForceDisplay.qml is a specialized G-force visualization card for the SensorMenu.

Properties

property real lateralG: 0
property real longitudinalG: 0
property real magnitude: 0
property bool connected: false
property int decimalPlaces: 2
property real maxG: 1.5

Features

  • Trail history — A ListModel stores the last 30 G-force readings (sampled every 50ms). These are rendered as a fading trail behind the current position indicator.
  • 2D plot — Lateral G maps to X-axis, longitudinal G to Y-axis, rendered within a circular boundary defined by maxG
  • Label header with icon and "G-FORCE" text
  • Themed — Uses App.Style.headerBackgroundColor for the card background and App.Style.accent for the indicator
// Trail sampling timer
Timer {
    running: connected
    interval: 50
    repeat: true
    onTriggered: {
        trailModel.append({ "gx": lateralG, "gy": longitudinalG })
        if (trailModel.count > 30)
            trailModel.remove(0)
    }
}

SensorCard

frontend/SensorCard.qml is a generic sensor reading display card used in SensorMenu.

Properties

property string label: ""     // Sensor name
property string value: "--"   // Current reading
property string unit: ""      // Unit suffix
property string icon: ""      // Unicode icon
property real barValue: -1    // 0-1 for progress bar, -1 hides it
property bool connected: false

Layout

A vertical ColumnLayout with:

  1. Label row — Icon + sensor name in secondary text, centered
  2. Value — Large dp(36) bold text, centered. Shows "--" when disconnected.
  3. Unit — Smaller text below the value
  4. Optional progress bar — Only visible when barValue >= 0

Usage Example

SensorCard {
    label: "HEADING"
    icon: "\u2B07"
    value: currentHeading.toFixed(1) + "° " + headingToCardinal(currentHeading)
    unit: "degrees"
    connected: imuConnected
}

OBDParameterModel

frontend/OBDParameterModel.qml is a pragma Singleton that defines all 93 OBD-II parameters with display metadata.

Parameter Structure

{ id: "SPEED",
  title: "Speed",
  unit: "MPH",
  min: 0,
  max: 160 }

Key Properties

// All 93 parameter definitions
readonly property var allParameters: [ ... ]

// Live values updated via obdManager signals
property var paramValues: ({})  // e.g., { "SPEED": 65, "RPM": 3200 }

Parameter Categories

CategoryCountExamples
Core engine18SPEED, RPM, COOLANT_TEMP, ENGINE_LOAD, THROTTLE_POS
Fuel system8+FUEL_LEVEL, SHORT/LONG_FUEL_TRIM, FUEL_PRESSURE, ETHANOL_PERCENT
O2 sensors24+O2_B1S1-B2S4, wide-range voltage/current variants
Catalyst4CATALYST_TEMP_B1S1, B1S2, B2S1, B2S2
Throttle/Accel5+THROTTLE_POS_B/C, ACCELERATOR_POS_D/E, RELATIVE_THROTTLE
Emissions3+COMMANDED_EGR, EGR_ERROR, EVAP_VAPOR_PRESSURE

The singleton pattern ensures all OBD views (MainMenu HomeOBDView, OBDMenu, settings) share the same parameter definitions and live values.

TerminalFeedback

frontend/TerminalFeedback.qml is a retro terminal-style output component used for displaying backend operation progress.

Properties

property int maxLines: 50
property bool autoScroll: true
property string title: "Output"
property bool showHeader: true
property color terminalBackground: "#1a1a1a"
property color textColor: "#00ff00"   // Classic terminal green
property color errorColor: "#ff4444"
property color infoColor: "#4a9eff"
property color successColor: "#44ff44"
property color warningColor: "#ffaa00"

API

// Add a line (auto-colors based on [PREFIX])
terminalOutput.appendLine("[SUCCESS] DTC cleared")
terminalOutput.appendLine("[ERROR] Connection failed")
terminalOutput.appendLine("[WARN] Check Engine Light is ON")

// Clear all output
terminalOutput.clear()

Environment Features

  • Corner brackets — Uses the CornerBrackets component when terminalCornerBrackets is active (Spacecraft)
  • Scanline overlay — A Canvas draws horizontal lines every 3px at 4% opacity to simulate CRT scanlines (Spacecraft)
  • Accent border — Border color uses the theme accent at 40% opacity when enabled
  • Top-edge highlight — Accent-colored 1px line along the top edge
  • Accent scroll bar — Themed scrollbar for the Flickable content area

Usage

TerminalFeedback {
    id: terminalOutput
    title: "OBD Diagnostics"
    maxLines: 100
    Layout.fillWidth: true
    Layout.fillHeight: true
}

CornerBrackets

frontend/CornerBrackets.qml is a pulsing corner bracket overlay for the Spacecraft environment theme.

Implementation

Eight Rectangle primitives (two per corner, one horizontal and one vertical) are positioned at the parent's corners. They pulse with a slow sine-wave opacity animation:

Item {
    id: brackets
    anchors.fill: parent
    property real bracketLength: App.Spacing.dp(12)

    // Pulsing opacity
    property real _pulse: 0.5
    SequentialAnimation on _pulse {
        running: brackets.visible
        loops: Animation.Infinite
        NumberAnimation { to: 0.8; duration: 2000; easing.type: Easing.InOutSine }
        NumberAnimation { to: 0.3; duration: 2000; easing.type: Easing.InOutSine }
    }

    property color _color: Qt.rgba(
        App.Style.accent.r, App.Style.accent.g,
        App.Style.accent.b, _pulse)

    // Top Left (horizontal + vertical)
    Rectangle { width: bracketLength; height: 1; color: _color
        anchors.top: parent.top; anchors.left: parent.left }
    Rectangle { width: 1; height: bracketLength; color: _color
        anchors.top: parent.top; anchors.left: parent.left }

    // ... same pattern for Top Right, Bottom Left, Bottom Right
}

Usage

Drop inside any Rectangle parent. The caller controls visibility; the pulse animation runs automatically:

Rectangle {
    id: myCard
    radius: 2

    CornerBrackets {
        visible: App.EnvironmentTheme.active.cornerBrackets
    }
}
Performance: The animation only runs when brackets.visible is true, so there is zero cost in Standard and Deep Sea environments where corner brackets are disabled.
