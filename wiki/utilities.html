Clock

backend/clock.py — QML name: clock

A simple QTimer-based clock. It formats the time every second (honouring clockShowSeconds) but emits timeChanged only when the text actually changed, so without seconds QML bindings re-evaluate once a minute instead of sixty times. Respects the user's clock visibility and format preferences from SettingsManager.

Source Code

class Clock(QObject):
    timeChanged = Signal(str)

    def __init__(self, settings_manager):
        super().__init__()
        self._settings_manager = settings_manager
        self.timer = QTimer()
        self.timer.timeout.connect(self.update_time)
        self.timer.start(1000)  # Update every second

    def update_time(self):
        if not self._settings_manager.showClock:
            self._emit_if_changed("")
            return

        current_time = datetime.now()
        show_seconds = self._settings_manager.clockShowSeconds
        if self._settings_manager.clockFormat24Hour:
            time_str = current_time.strftime("%H:%M:%S" if show_seconds else "%H:%M")
        else:
            hour_min = current_time.strftime("%I:%M:%S" if show_seconds else "%I:%M")
            am_pm = current_time.strftime("%p").upper()
            time_str = f"{hour_min} {am_pm}"

        self._emit_if_changed(time_str)   # timeChanged only when the text differs

Behavior

  • Timer interval: 1000ms (1 second)
  • Format: Reads clockFormat24Hour setting each tick. 24h: "14:30", 12h: "02:30 PM"
  • Visibility: When showClock is false, emits empty string so QML hides the display
  • QML binding: clock.timeChanged signal carries the formatted time string

Logging Configuration

backend/logging_config.py

Centralized logging for the entire application. Provides two main functions:

setup_logging(debug, console, file)

Called once at startup in main.py. Initializes the Python logging system with rotating file handlers.

from backend.logging_config import setup_logging
setup_logging(debug=False)  # Normal mode
setup_logging(debug=True)   # Debug mode (--debug flag)

Parameters

get_logger(name)

Gets a hierarchical logger for a module. Converts Python module paths to clean octave.* names.

from backend.logging_config import get_logger
logger = get_logger(__name__)
logger.info("Application started")

Implementation Notes

  • Logger instances are cached in a module-level _loggers dict for fast repeat access
  • _initialized flag prevents double-initialization
  • Log directory is created automatically at the platform-specific config path + /logs/

Performance Monitor

backend/perf_monitor.py

Comprehensive performance monitoring exposed as a QObject with QML-bindable properties. Only active when --profile flag is passed.

Internal Components

_RingBuffer

Fixed-size ring buffer (deque-based) for numeric samples with cheap percentile calculation. Used for both event-loop latency and GIL jitter measurements. Capacity: 300 samples for GIL, 600 for loop (about 10 seconds at 60Hz).

_GILProbe

A daemon background thread that sleeps for 10ms intervals and measures the actual sleep duration. The jitter (actual - expected) approximates GIL contention time. Runs continuously until stopped.

Event-Loop Probe

A QTimer with interval 0 (fires on next event-loop iteration). Measures the delta between successive firings. High deltas indicate the event loop is blocked (UI stutter).

Reporting Cycle (Every 1 Second)

  1. Calculate loop latency statistics (avg, p50, p95, p99, max) from ring buffer
  2. Calculate GIL jitter statistics (avg, p99)
  3. Read CPU and memory usage via psutil (if available)
  4. Count active threads
  5. Write to terminal (color-coded), CSV file, and perf log file
  6. Report slow slots (p95 > 2ms) every 5 seconds
  7. Clear buffers and emit metricsUpdated signal

timed_slot Decorator

from backend.perf_monitor import timed_slot

@timed_slot
def my_slot(self):
    # This slot's execution time is automatically tracked
    # under the key "ClassName.my_slot"
    ...

Records per-call duration in a _RingBuffer keyed by fn.__qualname__. Reported when p95 exceeds 2ms.

Manual Instrumentation

# Time any code section
t = PerfMonitor.begin()
# ... expensive operation ...
PerfMonitor.end(t, "operation_name")

Detailed Report

The getDetailedReport() slot returns a multi-line string summarizing all tracked metrics and slot timings. Written to the perf log file on shutdown.

Command Server

backend/command_server.py

TCP server for remote control of OCTAVE. Only active with --profile flag. Listens on 127.0.0.1:9876.

Architecture

  CommandServer
    |
    +-- _ThreadedTCPServer (socketserver.ThreadingMixIn)
    |     |
    |     +-- _Handler (one per client connection)
    |     |     reads JSON lines, calls dispatch()
    |     |
    |     +-- dispatch(action, args)
    |           routes to appropriate manager method
    |
    +-- NavigationBridge
          QObject on main thread
          thread-safe QML navigation via QMetaObject.invokeMethod

NavigationBridge

Provides thread-safe navigation by executing QML method calls on the GUI thread:

class NavigationBridge(QObject):
    @Slot(str)
    def navigate_to(self, page: str):
        # Calls mainWindow.navigateTo(page) in QML
        QMetaObject.invokeMethod(root, "navigateTo", Q_ARG(str, page))

    @Slot()
    def go_home(self): ...
    @Slot()
    def go_back(self): ...

Action Dispatch

The dispatch method handles 40+ actions across 7 categories. It accesses managers via a dict passed at startup:

server.start(
    managers={
        "settings": settings_manager,
        "media": media_manager,
        "spotify": spotify_manager,
        "obd": obd_manager,
    },
    perf_monitor=perf_monitor,
    engine=engine
)

Settings Actions

The command server exposes three types of settings manipulation:

  • Boolean toggles: 13 settings (show_clock, vinyl_mode, obd_fast_mode, etc.) via toggle_setting and set_bool_setting
  • Numeric sliders: 10 settings with min/max clamping (ui_scale, blur_radius, etc.) via set_numeric_setting
  • String/enum: 6 settings with validation (theme, font, album_art_transition, etc.) via set_string_setting
