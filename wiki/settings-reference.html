Overview

All settings are managed by backend/settings_manager.py and persisted to settingsConfigure.json in the OS-specific config directory:

  • Windows: %APPDATA%/OCTAVE/settingsConfigure.json
  • macOS: ~/Library/Application Support/OCTAVE/settingsConfigure.json
  • Linux: ~/.config/OCTAVE/settingsConfigure.json
  • Android: <cwd>/OCTAVE/settingsConfigure.json

Settings are loaded at startup, validated against the default schema, and saved atomically (write to temp file, then rename). File locking is used cross-platform to prevent corruption from concurrent access.

Quick Panel: Many settings are registered in the SETTINGS_REGISTRY dictionary, which powers the dynamic Quick Panel UI. These settings can be pinned by users for quick access.

OBD Parameters: OCTAVE supports 87+ OBD-II PIDs. 19 are enabled by default (RPM, SPEED, COOLANT_TEMP, etc.). The full list includes O2 sensors (8 banks), catalyst temps, wide-range O2 voltage/current sensors, fuel system parameters, and diagnostic counters. Use the vehicle scan feature to detect which parameters your vehicle supports.

Persistence & File Format

Settings are stored as a single JSON file with atomic writes:

  1. Write to a temp file in the same directory
  2. Set restrictive permissions (Unix: chmod 600)
  3. Atomic rename to the final path (on Unix; on Windows, delete + rename)
  4. Cross-platform file locking via fcntl (Unix) or msvcrt (Windows)

On load, all settings are validated against the default schema. Invalid types are silently replaced with defaults. Unknown keys are preserved for forward compatibility.
