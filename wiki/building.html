Quick Start

# Build for current platform (creates venv, installs deps, builds)
python build_scripts/build.py

# Clean build artifacts only
python build_scripts/build.py --clean

# Clean then rebuild
python build_scripts/build.py --clean --build-after-clean
Build Location: The build script uses the system temp directory (/tmp/OCTAVE_build and /tmp/OCTAVE_dist) for intermediate files to avoid Dropbox sync issues. Final output is copied to dist/ in the project root.

Unified Build Script

build_scripts/build.py

The unified build script handles all platforms with a single entry point. It performs these steps:

  1. Setup: Creates a virtual environment in venv/ if not present, installs requirements.txt and PyInstaller
  2. Clean: Removes build/, dist/, __pycache__/, and .pyc files recursively
  3. Build: Runs PyInstaller with build_scripts/octave.spec
  4. Package: Creates platform-specific installer (Inno Setup / DMG / AppImage)
  5. Copy: Copies build output from temp dir to project dist/ folder

The spec file defines exactly what gets bundled into the executable:

Hidden Imports

The spec file declares hidden imports for all PySide6 modules, backend dependencies, and platform-specific keyring backends:

hidden_imports = [
    'PySide6.QtCore', 'PySide6.QtGui', 'PySide6.QtQml',
    'PySide6.QtQuick', 'PySide6.QtQuickControls2',
    'PySide6.QtMultimedia', 'PySide6.QtNetwork',
    'mutagen', 'spotipy', 'obd',
    'numpy', 'scipy', 'keyring', 'PIL',
    # + platform-specific keyring backends
    # + all PySide6 submodules via collect_submodules()
]

Excluded Modules

To reduce bundle size, these are excluded: tkinter, matplotlib, cv2, pandas, pytest.

Windows Build

Windows

Requirements

  • Python 3.8+
  • (Optional) Inno Setup 6 for creating the installer

Output

  • dist\OCTAVE\OCTAVE.exe - Standalone executable (portable, distribute the whole folder)
  • dist\OCTAVE_Setup_1.0.0.exe - Inno Setup installer (if Inno Setup is installed)

Inno Setup Installer

The installer script at build_scripts/installer_windows.iss creates a professional Windows installer with Start Menu shortcuts and uninstaller.

macOS Build

macOS

Requirements

  • Python 3.8+
  • Xcode Command Line Tools (xcode-select --install)

Output

  • dist/OCTAVE.app - Application bundle
  • dist/OCTAVE_1.0.0.dmg - DMG installer with Applications symlink

App Bundle Info.plist

The spec file configures the macOS app bundle with:

bundle_identifier: 'com.waybettersolutions.octave'
NSHighResolutionCapable: True
NSRequiresAquaSystemAppearance: False  # Dark mode support
LSMinimumSystemVersion: '10.14.0'
# Bluetooth and microphone usage descriptions included

DMG Creation

The build script creates a DMG using hdiutil create in UDZO (compressed) format, with an Applications symlink for drag-to-install.

Code Signing: Unsigned macOS apps trigger Gatekeeper warnings. Users can bypass with xattr -cr /Applications/OCTAVE.app. For distribution, sign with a Developer ID certificate.

Linux Build

Linux

Requirements

  • Python 3.8+
  • Build essentials: sudo apt install build-essential
  • wget (for automatic appimagetool download)

Output

  • dist/OCTAVE/octave - Standalone executable
  • dist/OCTAVE-<version>-linux-x86_64.AppImage / -linux-aarch64.AppImage - Portable single-file AppImages (the aarch64 one is built by the cpp-build-linux-arm64 job for Orange Pi / Raspberry Pi class hardware)

AppImage Structure

The build script creates an AppDir with proper structure:

OCTAVE.AppDir/
  AppRun                    # Shell script entry point
  octave.desktop            # Desktop entry file
  usr/bin/                  # All PyInstaller output
  usr/share/applications/   # Desktop entry copy
  usr/share/icons/          # App icon

The AppRun script sets critical environment variables:

export QT_QPA_PLATFORM_PLUGIN_PATH="${HERE}/usr/bin/PySide6/Qt/plugins/platforms"
export QML2_IMPORT_PATH="${HERE}/usr/bin/PySide6/Qt/qml"

The CI workflow installs these system packages for Linux builds:

  libxcb-xinerama0 libxcb-cursor0 libxkbcommon0 \
  libgl1-mesa-glx libegl1 libfuse2

Release Job

The release job runs only on version tags. It downloads all artifacts, zips them, and creates a GitHub Release with auto-generated release notes using softprops/action-gh-release@v2.

Phone mirror bundling

No scrcpy binary is bundled or required. The C++ binary embeds the scrcpy server jar (tools/scrcpy-server/) as a Qt resource and CI ships Google's adb next to the executable (python scripts/fetch_platform_tools.py, pinned and SHA-256 verified). libavcodec is an optional build dependency for the H.264 decoder; without it phoneMirrorManager.nativeAvailable is false.

Android APK Build

Android

The Android .apk is built from the C++ / Qt 6 tree in src/ using Qt's qt-cmake cross-compile wrapper — not from Python. The Python backend is desktop-only and is never packaged for mobile; platform-specific behavior is gated behind #ifdef Q_OS_ANDROID in the C++ managers. (The former Buildozer / python-for-android path has been removed.)

Full toolchain: See BUILD.md (Android build) for the complete setup — Qt for Android 6.7.3, OpenJDK 17, Android SDK + NDK 26.1.10909125, and APK signing. A condensed walkthrough is on the Getting Started page.

Build Troubleshooting

"DLL not found" on Windows

Install the Visual C++ Redistributable: Download link

"App is damaged" on macOS

xattr -cr /Applications/OCTAVE.app

Missing Qt Plugins

Ensure PySide6 version matches between requirements.txt and the build environment. Version mismatches cause missing plugin errors at runtime.

AppImage Won't Run

# Make executable
chmod +x OCTAVE-x86_64.AppImage

# If FUSE unavailable, extract and run
./OCTAVE-x86_64.AppImage --appimage-extract
./squashfs-root/AppRun

Dropbox Sync Interference

The build script uses temp directories to avoid Dropbox trying to sync intermediate build files. If you see file locking errors during build, close Dropbox or move the project outside the synced folder.
