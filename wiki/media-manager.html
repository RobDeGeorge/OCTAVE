Overview

The MediaManager class (src/managers/mediamanager.{h,cpp} in the C++ backend, backend/media_manager.py in the Python backend) handles all local audio file playback for OCTAVE. It wraps Qt's QMediaPlayer and QAudioOutput, manages a metadata and album art cache, extracts dominant colors from album art for dynamic theming, and provides full playlist support with shuffle, skip, and playback resume.

It is registered as a QML context property named mediaManager and exposes all playback controls as Slots, with state changes broadcast via Signals.

All Platforms

Supported Audio Formats

The following file extensions are recognized during library scanning:

AUDIO_EXTENSIONS = ('.mp3', '.m4a', '.flac', '.ogg', '.opus', '.wav')

In the Python backend, MP3 files use the mutagen library's ID3 and MP3 classes for metadata. M4A/MP4/AAC files use mutagen.mp4.MP4. Other formats fall back to mutagen.File for basic duration information. The C++ backend reads the same tags with TagLib (ID3v2 APIC, MP4 covr, FLAC and Ogg/Opus pictures); the list lives in MediaManager::s_audioExtensions.

QMediaPlayer Integration

MediaManager creates a QMediaPlayer with a QAudioOutput in its constructor. Key configuration: 

self._player = QMediaPlayer()
self._audio_output = QAudioOutput()
self._player.setAudioOutput(self._audio_output)
self._audio_output.setVolume(0.5)

# Increase probe size for reliable format detection
self._player.setProperty("probe-size", 10000000)  # 10MB
self._player.setProperty("analyzeduration", 5000000)  # 5 seconds

Connected signals from QMediaPlayer:

  • durationChanged - forwarded directly to QML
  • positionChanged - forwarded directly to QML
  • mediaStatusChanged - routed to _handle_media_status() for end-of-track and error detection
  • errorOccurred - triggers automatic playback recovery

A QTimer at 100ms interval supplements position updates for smooth UI slider tracking.

Library Scanning

The media directory defaults to backend/media/ (Python) or <application dir>/media (C++ desktop) but is typically overridden by the user via SettingsManager's mediaFolder property, whose default is the empty string (meaning "use the built-in default"). The C++ Android build uses the system Music location instead, falling back to /sdcard/Music.

get_media_files() scans the configured directory for files matching AUDIO_EXTENSIONS: 

@Slot(result=list)
def get_media_files(self, emit_signal=True):
    mp3_files = []
    if os.path.exists(self.media_dir):
        for file in os.listdir(self.media_dir):
            if file.lower().endswith(AUDIO_EXTENSIONS):
                mp3_files.append(file)
    if emit_signal:
        self.mediaListChanged.emit(mp3_files)
    return mp3_files

The scanProgress signal provides terminal-style feedback during deeper scans (e.g., when building the "All Music" playlist across subdirectories).

Path Safety
The helper is_safe_path(base_path, target_path) validates that any resolved path stays within the base directory, preventing path traversal attacks from malicious filenames.

Metadata Caching

Metadata is cached in self._metadata_cache (dict: filename to metadata dict) with a maximum of 1000 entries. Each entry stores: 

{
    "artist": "Artist Name",
    "album": "Album Name",
    "title": "Track Title",
    "duration": 245  # seconds
}

The _cache_metadata() method handles format-specific extraction:

  • MP3: Uses ID3() for tags (TPE1, TALB, TIT2) and MP3() for duration. Also extracts album art from APIC frames in the same read.
  • M4A/MP4/AAC: Uses mutagen.mp4.MP4. Tags are \xa9ART, \xa9alb, \xa9nam. Album art from covr tags.
  • Others (FLAC, OGG, etc.): Falls back to mutagen.File for duration only.

All metadata strings are sanitized by sanitize_metadata() which:

  • Removes control characters
  • Collapses multiple spaces
  • Truncates to 200 characters with ellipsis

Album Art Extraction

Album art is cached in self._album_art_cache (dict: album_id to file:// URL) with a maximum of 500 cached files on disk in the backend/temp/ directory (<application dir>/temp in the C++ desktop build, the app data temp/ folder on Android).

Album ID Generation

Each album is identified by a composite key: "{album}_{artist}". If metadata is unavailable, a SHA-256 hash of the filename is used as fallback.

Extraction Flow

  1. Check if album_id is already in _album_art_cache (instant return)
  2. Run LRU cache management (evict least-accessed item if at capacity)
  3. Read album art from the audio file:
    • MP3: iterate ID3 frames for APIC tags
    • M4A: read covr tags
  4. Write image data to temp file with SHA-256 hash-based filename (e.g., cover_a1b2c3d4.jpg)
  5. Store the file:// URL in the cache and return it

Optimization: Single-Read Cache Population

The _cache_metadata() method also calls _cache_album_art_from_id3() to extract album art from the already-loaded ID3 object. This means a single file read populates both the metadata cache and the album art cache, making subsequent get_album_art() calls instant.

Color Extraction and Theming

When the "Album Art Capture" theme is active, MediaManager extracts dominant colors from album art to generate a complete dynamic theme palette. Uses Qt's QImage (no Pillow required).

Extraction Pipeline

  1. Resize album art to 50x50 pixels via QImage.scaled() (smooth transformation)
  2. Run k-means clustering (_kmeans_colors(), pure Python / C++ port with the same k=5, max 10 iterations) to find 5 dominant colors
  3. Sort colors by vibrancy (saturation * value in HSV space)
  4. Determine if image is dark or light based on average luminance
  5. Call _generate_theme_from_colors() to build a full theme object

Theme Generation

_generate_theme_from_colors() takes the sorted color palette and generates a comprehensive theme JSON with keys for every UI element:

  • base, baseAlt - Background colors (dark/light variants of primary)
  • accent - Primary accent with boosted saturation
  • text.primary, text.secondary - WCAG-contrast-checked text colors
  • states.hover, states.paused, states.playing - Interaction states
  • sliders.volume, sliders.media, sliders.settings - Per-slider accent colors
  • bottombar.* - 12+ individual colors for navigation buttons
  • mediaroom.* - Player control colors
  • obd.* - OBD gauge colors

All icon/accent colors are run through ensure_icon_contrast() which enforces a minimum WCAG contrast ratio of 3.0 against the background, brightening or darkening as needed.

Colors are capped at 85% brightness via cap_brightness() to prevent washed-out pastels.

Playback Control

Playing a File

@Slot(str)
def play_file(self, filename):
    # Initialize playlist if needed
    # Find file index in current playlist
    # Resolve full path via _get_file_path() (handles All Music multi-folder)
    file_path = self._get_file_path(filename)
    url = QUrl.fromLocalFile(file_path)
    self._player.setSource(url)
    self._player.play()
    # Pre-populate metadata + album art caches BEFORE emitting
    # currentMediaChanged so QML bindings get instant cache hits
    self._emit_metadata(filename)
    self.currentMediaChanged.emit(filename)
    self._precache_timer.start()

Shuffle Logic

Shuffle is a toggle stored in self._shuffle. When enabled, the current playlist is randomized via _shuffle_playlist(): 

def _shuffle_playlist(self):
    files = self._get_current_playlist_files()
    if not files:
        files = self.get_media_files()
    shuffled = files.copy()
    random.shuffle(shuffled)
    return shuffled

When shuffle is toggled off, the playlist reverts to alphabetical order (sorted with punctuation and underscores stripped: re.sub(r'[^\w\s]|_', '', x.lower())).

Shuffle state can be persisted across restarts via SettingsManager's persistShuffleState and lastShuffleState settings.

Playlist Management

MediaManager supports multiple playlists discovered from the media folder structure:

  • self._playlists - Dict: playlist name to {path, files, song_count}
  • self._playlist_names - Ordered list of playlist names
  • self._current_playlist_name - Active playlist name
  • self._library_root - Main source folder path

"All Music" Playlist

A special "All Music" mode aggregates files from all subdirectories. Since files from different folders may have the same name, self._all_music_file_paths maps each filename to its full directory path. The _get_file_path() helper resolves the correct path: 

# When All Music is active, lookup the directory for this filename
if self._is_all_music_active and filename in self._all_music_file_paths:
    return os.path.join(self._all_music_file_paths[filename], filename)

Display Name Mapping

self._display_names maps filenames to cleaned display names, persisted in display_names.json within the app data directory. This allows cleaned names to survive across sessions without re-scanning.

Volume and Mute

Volume Control

The user's volume (_volume / m_volume), mute and a ducking factor are kept separately; one helper (_apply_output_volume() / applyOutputVolume()) computes what the QAudioOutput actually gets: 0 while muted, otherwise volume × duck. getVolume() reports the user's volume, never the ducked or muted output level. 

@Slot(float)
def setVolume(self, volume):
    volume = max(0.0, min(1.0, float(volume)))
    self._volume = volume
    if self._is_muted:
        self._previous_volume = volume  # Store for unmute
    self._apply_output_volume()         # 0 if muted else volume × duck
    self.volumeChanged.emit(volume)

Ducking

setDucking(factor) (both backends) temporarily attenuates the output for another source that needs to be heard, today the mirrored phone's audio (see Phone Mirror). The factor is ramped with a QVariantAnimation: 80 ms attack so a navigation prompt is not stepped on, 500 ms release so music does not jump back between sentences. Volume changes and mute keep working while ducked.

Mute Toggle with Guard

The toggle_mute() method uses a lock guard (_mute_toggle_locked) with a 150ms debounce to prevent rapid toggling from corrupting the volume state: 

@Slot()
def toggle_mute(self):
    if self._mute_toggle_locked:
        return
    self._mute_toggle_locked = True
    try:
        if self._is_muted:
            restore_vol = self._previous_volume if self._previous_volume > 0.0 else 0.5
            self._audio_output.setVolume(restore_vol)
        else:
            if self._audio_output.volume() > 0.0:
                self._previous_volume = self._audio_output.volume()
            self._audio_output.setVolume(0.0)
        self._is_muted = not self._is_muted
        self.muteChanged.emit(self._is_muted)
    finally:
        QTimer.singleShot(150, self._unlock_mute_toggle)

Playback State Resume

MediaManager persists the current song, position, and playlist name via SettingsManager for resume on next startup. A debounce timer (_save_state_timer, 1 second, single-shot) prevents disk writes on every rapid track change: 

self._save_state_timer = QTimer()
self._save_state_timer.setInterval(1000)
self._save_state_timer.setSingleShot(True)
self._save_state_timer.timeout.connect(self._save_playback_state_now)

On shutdown, if the debounce timer is active, it is stopped and the state is flushed immediately in __del__.

Neighbor Pre-caching

After a track change, a single-shot timer (_precache_timer, 80ms) triggers _precache_neighbors_start() which pre-populates metadata and album art caches for the previous and next tracks in a background thread (a threading.Thread in Python, QtConcurrent::run() in C++). This ensures that the next skip is instant with no visible loading delay in the QML UI.

Error Recovery

MediaManager includes automatic recovery for common playback failures:

  • EndOfMedia - Automatically calls next_track()
  • StalledMedia / InvalidMedia - Triggers _attempt_playback_recovery()
  • Player errors - Also triggers recovery

The recovery method re-seats the source and restores position:

def _attempt_playback_recovery(self):
    current_file = self.get_current_file()
    position = self._player.position()
    was_playing = self._is_playing
    file_path = self._get_file_path(current_file)
    self._player.setSource(QUrl.fromLocalFile(file_path))
    if position > 0:
        self._player.setPosition(position)
    if was_playing:
        self._player.play()
    # Restore mute state after recovery
    if self._is_muted:
        self._audio_output.setVolume(0.0)

The toggle_play() method also checks for bad player states (InvalidMedia, NoMedia, StalledMedia) before resuming and triggers recovery if needed.

How to Modify / Extend

Adding a New Audio Format

  1. Add the extension to the AUDIO_EXTENSIONS tuple (Python) and s_audioExtensions (C++)
  2. Add format-specific metadata extraction in _cache_metadata() (add an elif branch)
  3. Add album art extraction in get_album_art() if the format supports embedded art

Adding a New Playback Feature

  1. Add a Signal at the class level
  2. Add internal state variable in __init__
  3. Add a @Slot method that QML can call
  4. Emit the signal when state changes
  5. If the feature should persist, add a corresponding setting in SettingsManager
Threading Note
MediaManager runs on the main thread. Heavy operations like library scanning emit progress signals but the scan itself is synchronous. The pre-cache neighbor operation uses a background thread to avoid blocking the UI during track transitions. Both backends expose the same slots and signals, so QML never needs to know which one is running.
