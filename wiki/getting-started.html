What OCTAVE Is

OCTAVE is a car head unit you build yourself: the screen in the dash, running on a Raspberry Pi, a laptop or an old Android tablet. It puts your music, your phone and the car's own data (speed, engine temperature, the reason for the check-engine light) on one screen. It is free and open source.

The fastest way to see it is the browser demo. It is the real app running in a web page, with nothing to install.

To have it on your own device, install a release as described below. To build it from the source code instead, see Building.

Installing

Every release is on the GitHub Releases page. Download the one file for your device. <version> below stands for the release number, such as 0.9.6.

DeviceFile
Windows 10 or newer, 64-bitOCTAVE-<version>-windows-x86_64.exe
macOSOCTAVE-<version>-macos.dmg
Linux PCOCTAVE-<version>-linux-x86_64.AppImage
Raspberry Pi, Orange Pi and other 64-bit ARM boardsOCTAVE-<version>-linux-aarch64.AppImage
Android 11 or newerOCTAVE-<version>-android-arm64-v8a.apk

There is no iPhone or iPad release.

Windows

  1. Download OCTAVE-<version>-windows-x86_64.exe and run it. It is an installer.
  2. Follow the installer. It asks for administrator rights, because it installs into Program Files.
  3. Start OCTAVE from the Start menu.

The installer is not signed, so Windows may show a blue "Windows protected your PC" box. Choose More info, then Run anyway.

macOS

A .dmg is published with every release: OCTAVE-<version>-macos.dmg. Open it and drag OCTAVE to Applications. The app is not signed with an Apple developer certificate, so macOS will warn you the first time you open it.

Linux

The Linux release is an AppImage: one file that is the whole app. Nothing is installed.

  1. Download OCTAVE-<version>-linux-x86_64.AppImage.
  2. Make it runnable. In a file manager this is a tick box in the file's properties. In a terminal: 
    chmod +x OCTAVE-*.AppImage
  3. Double-click it, or run ./OCTAVE-*.AppImage.

If it does not start, your system is probably missing FUSE 2, which AppImages use to open themselves. Install it (sudo apt install libfuse2 on Debian and Ubuntu, sudo pacman -S fuse2 on Arch), or run the file without it: 

./OCTAVE-*.AppImage --appimage-extract-and-run

The AppImage is built on Ubuntu 22.04, so it needs a system at least that new.

Raspberry Pi and Other ARM Boards

The same as Linux, with the other file: OCTAVE-<version>-linux-aarch64.AppImage. It needs a 64-bit system.

One thing is not in this file: adb, the small tool OCTAVE uses to talk to an Android phone. If you want your phone on the screen, install it: 

sudo apt install adb

Wiring a board into a car (power, sensors, a volume knob) is on the Hardware Setup page.

Android

OCTAVE is not on the Play Store. You install the file yourself, which Android calls sideloading.

  1. On the phone or tablet, download OCTAVE-<version>-android-arm64-v8a.apk.
  2. Open the downloaded file. Android asks whether your browser or file manager may install apps: allow it, then tap Install.
  3. Open OCTAVE. Allow access to your music when it asks.

The Android app plays your music and reads your car through a Bluetooth LE adapter. It does not mirror another phone, and it cannot read trouble codes yet.

The Screen

OCTAVE opens on Home. On a fresh install Home shows a window for your phone in the middle, the playing song under it, and four readings from the car at the sides. Nothing is connected yet, so the parts show buttons for connecting them: Connect Phone, Connect Music, Connect Vehicle.

The bar along the bottom is always there. Its five buttons open the five sections:

SectionWhat is there
HomeThe overview you see while driving.
OBDThe car: live readings, trouble codes, the history of your drives.
MediaYour music.
SensorsPitch, roll, heading and G-force, and a 3D view of your vehicle. These need a motion sensor.
SettingsEverything you can change.

The bar also holds the music controls, the volume and the clock. See Bottom Bar.

You can also swipe. A quick sideways swipe on a page opens the next section: swipe left for the one to the right in the bar, swipe right for the one to the left. It stops at the first and last section.

Four First Things to Do

Add Your Music

  1. Put your songs in one folder on the device.
  2. Open Media. It says "No Music Loaded". Tap Connect Music, then Local Music.
  3. Pick the folder. Your songs appear at once.

You can change the folder later in Settings > Media > Library & Playback > Library Folder. File types, playlists and Spotify are on the Media Manager page.

Try the Simulated Car

You do not need a car, or any hardware, to see the car side of OCTAVE. A simulated car is built in.

  1. Open OBD. It says "No vehicle connected".
  2. Tap Connect Vehicle.
  3. In the list, tap Simulated car.

The car starts driving by itself. Open Live Data to watch its readings, then go back to Home to see the gauges move. For a real car you need an ELM327 adapter, a small plug for the port under the dashboard: see OBD Manager, which also says more about the simulated car.

Connect Your Phone

An Android phone can appear on OCTAVE's screen, where you can touch it. This works when OCTAVE runs on a computer or a Pi, not in the Android app. Nothing is installed on the phone.

  1. On the phone, turn on USB debugging in its Developer options.
  2. Plug the phone into the OCTAVE device with a USB cable.
  3. On Home, tap Connect Phone.
  4. On the phone, allow USB debugging when it asks.

The full steps, Wi-Fi without a cable, and iPhones over AirPlay are on the Phone Mirror & Android Auto page.

Pick a Home Screen and a Theme

  1. Open Settings > Display > Layout and find Home Screen. Each choice is a card with a picture: Cockpit, Glass, Trail, Retro, Rings, Telemetry, Classic, and the Home you started with. Tap one and it is Home.
  2. Open Settings > Display > Appearance and find Theme. Tap a colour theme, light or dark. With Album Art Capture on, the colours come from the cover of the song that is playing.

You can also make a Home of your own: see Gauges & Dashboards. Themes are explained on the Theme System page.

Where Your Settings and Logs Are

OCTAVE keeps your settings, your dashboards and the record of your drives in one folder, the config folder. Where it is on each system, what is in it, and how to back it up or start afresh are on the Settings Manager page.

When something goes wrong, OCTAVE writes it to log files in that folder. Where they are and how to read them is under Logging. The Troubleshooting page lists common problems and their fixes.

Updating and Uninstalling

To see whether there is a newer release, open Settings > About and tap Check for Updates under Software Updates. If there is one, a Download button opens its page. OCTAVE does not install the update itself: download the new file and install it as you did the first time.

DeviceTo updateTo uninstall
WindowsRun the new installer. It replaces the old version and keeps your settings.Use "Uninstall OCTAVE" in the Start menu, or Windows' list of installed apps. It asks whether to delete your settings too; answer No to keep them.
macOSReplace the app in Applications with the one from the new .dmg.Delete the app from Applications.
Linux, Raspberry PiDownload the new AppImage and run that one. Delete the old file.Delete the AppImage.
AndroidInstall the new .apk over the old app. Your settings are kept.Uninstall it like any other app.

On macOS and Linux the config folder stays behind when you delete the app. Delete it too if you want nothing left.

If Android refuses to install an update, the app on the device was signed with a different key (releases up to 0.9.3 were). Uninstall the old app first, then install the new one. This loses its settings.
