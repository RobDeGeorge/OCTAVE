Pair this browser

On the car's screen open Settings > Device > Service and press Show a code, then enter it here. The token is kept in this browser; revoke it there any time.

Import a dashboard

Paste a shared dashboard (its JSON), or pick a file. It is added as a new dashboard; nothing is overwritten.

Tap a widget to select it, drag it to move (widgets in the way swap or move aside), drag its corner to resize. On the car, the dashboards page shows this one while "Show on the car" is on.
